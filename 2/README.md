## 4. Часть 1. Преобразование регулярного выражения в конечный автомат

### 4.1. Построение регулярного выражения
Язык $L_2$ задает цепочки, содержащие не менее 4 символов $a$, за которыми следует от 0 до 3 символов $b$.

Математическая запись регулярного выражения:
$$aaaaa^*(\lambda + b + bb + bbb)$$

В среде JFLAP пустая цепочка $\lambda$ обозначается символом `!`, поэтому введенное выражение имеет вид:
`aaaaa*(!+b+bb+bbb)`

## 5. Часть 2. Преобразование регулярной грамматики в КА и обратное получение РВ

### 5.1. Построение праволинейной грамматики

Для языка $L_2$ составлена следующая праволинейная грамматика:

* $S \to aA$
* $A \to aB$
* $B \to aC$
* $C \to aD$
* $D \to aD \mid bE \mid \lambda$
* $E \to bF \mid \lambda$
* $F \to b \mid \lambda$

Символы $S, A, B, C$ обеспечивают обязательную генерацию первых 4 символов $a$. Нетерминал $D$ позволяет генерировать произвольное количество дополнительных символов $a$, а цепочка $D \to E \to F$ ограничивает количество символов $b$ максимум тремя.

### 5.4. Преобразование конечного автомата в регулярное выражение (Convert FA to RE)

![](photo/2-16.jpg)

Обратное получение регулярного выражения выполнено методом последовательного исключения состояний (State Collapser):

1. **Объединение параллельных переходов:** кратные дуги между состояниями заменяются одной дугой с объединением символов (например, переходы по $b$ и $\lambda$ объединяются в $b+\lambda$):

2. **Добавление недостающих переходов:** между всеми несоединенными вершинами добавляются переходы по пустому множеству $\emptyset$ (кнопка *Complete*):

![](photo/2-18.jpg)

3. **Последовательное исключение промежуточных состояний:** при удалении каждой вершины пересчитываются регулярные выражения на проходящих через нее путях:

![](photo/2-19.jpg)

4. **Полученное регулярное выражение:**

$$aaaaa^* + aaaaa^*b + aaaaa^*bb(b+\lambda)$$

## 6. Часть 3. Доказательство нерегулярности языка (Pumping Lemma)

### 6.1. Аналитическое доказательство

**Исследуемый язык:**
$$L_{28} = \{a^n b^l a^k : k \ne n + l\}$$

Докажем нерегулярность языка $L_{28}$ методом от противного с использованием леммы о разрастании для регулярных языков.

1. **Предположение:** пусть язык $L_{28}$ регулярен. Тогда существует некоторая константа накачки $p \ge 1$ такая, что любое слово $w \in L_{28}$ длины $|w| \ge p$ можно представить в виде $w = xyz$, где:
   * $|xy| \le p$
   * $|y| \ge 1$
   * $\forall i \ge 0: x y^i z \in L_{28}$

2. **Выбор слова:** выберем слово $w \in L_{28}$:
$$w = a^p b^{p!} a^{p + 2(p!)}$$

   Параметры слова: $n = p$, $l = p!$, $k = p + 2(p!)$.  
   Проверим условие принадлежности:
   $$n + l = p + p! \ne p + 2(p!) = k$$
   Следовательно, слово $w$ действительно принадлежит языку $L_{28}$, а его длина заведомо больше $p$.

3. **Анализ подстроки $y$:**  
   По первому условию леммы $|xy| \le p$. Так как слово $w$ начинается с блока из $p$ символов $a$, подстрока $xy$ целиком лежит внутри этого блока. Следовательно, подстрока накачки $y$ состоит исключительно из символов $a$:
   $$y = a^m, \quad 1 \le m \le p$$

4. **Подбор параметра накачки $i$:**  
   Рассмотрим слово после накачки $w_i = x y^i z$. При накачке изменяется только количество символов в первом блоке $a$:
   $$n' = p + (i - 1)m$$

   Подберем $i$ так, чтобы нарушить условие языка и получить $n' + l = k$:
   $$(p + (i - 1)m) + p! = p + 2(p!)$$
   $$(i - 1)m = p! \implies i = 1 + \frac{p!}{m}$$

   Так как $1 \le m \le p$, число $m$ гарантированно входит делителем в $p!$. Следовательно, значение $\frac{p!}{m}$ является целым положительным числом, а параметр $i = 1 + \frac{p!}{m}$ — целое число, причем $i \ge 2$.

5. **Противоречие:**  
   При выбранном значении $i$:
   $$n' + l = (p + p!) + p! = p + 2(p!) = k$$
   Равенство $k = n' + l$ означает, что слово $w_i \notin L_{28}$.  
   Это противоречит утверждению леммы о том, что $x y^i z \in L_{28}$ для всех $i \ge 0$.

**Вывод:** предположение неверно, язык $L_{28}$ не является регулярным.

### 6.2. Практическое моделирование в JFLAP

Поскольку тренажер Pumping Lemma в JFLAP содержит фиксированный список классических языков и не позволяет задавать произвольный пользовательский язык $L_{28}$, практическая демонстрация принципа леммы в режиме игры против компьютера («Computer goes first») проведена на предустановленном языке $L = \{a^n b^n : n \ge 0\}$.

![](photo/3-1.jpg)

**Ход эксперимента:**
1. Компьютер задал длину накачки $m = 7$.
2. В качестве контрпримера введено слово $w = a^9 b^9 \in L$ (длина $|w| \ge 7$).
3. Компьютер разбил слово на части: $x = \lambda$, $y = a^7$, $z = a^2 b^9$.
4. При выборе $i = 0$ (выкачивание) получена строка:
$$x y^0 z = a^2 b^9 \notin L$$
Так как количество символов $a$ и $b$ не совпало, цепочка не принадлежит языку. Цель достигнута, победа за пользователем («YOU WIN!»), что наглядно иллюстрирует нарушение условий регулярности.
