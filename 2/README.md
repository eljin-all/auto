## 6. Часть 3. Доказательство нерегулярности языка (Pumping Lemma)

### 6.1. Формальное аналитическое доказательство

**Исследуемый язык:**

$$L_{28} = \{a^n b^l a^k : k \ne n + l\}$$

Докажем методом от противного, что $L_{28}$ не является регулярным.

1. **Предположение:** Пусть $L_{28}$ регулярен. Тогда существует целое число $p \ge 1$ (длина накачки), такое, что любое слово $w \in L_{28}$ длины $|w| \ge p$ разбивается на три части $w = xyz$, для которых выполняются условия:


* $|xy| \le p$

* $|y| \ge 1$

* $\forall i \ge 0: x y^i z \in L_{28}$



2. **Выбор слова:** Выберем строку $w \in L_{28}$ длины больше $p$:
$$w = a^p b^{p!} a^{p + 2(p!)}$$



Здесь $n = p$, $l = p!$, $k = p + 2(p!)$. Так как $n + l = p + p! \ne p + 2(p!) = k$, слово принадлежит языку $L_{28}$.


3. **Анализ структуры подстроки накачки:**
Так как $|xy| \le p$, а первые $p$ символов цепочки состоят только из букв $a$, подстрока $y$ содержит только символы $a$:


$$y = a^m, \quad 1 \le m \le p$$


4. **Выбор коэффициента накачки:**
Рассмотрим слово $w_i = x y^i z$. При накачке меняется только число символов первого блока $a$: новое значение равно $n' = p + (i - 1)m$.


Подберем $i$ так, чтобы нарушить неравенство $k \ne n' + l$, то есть получить $n' + l = k$:



$$(p + (i - 1)m) + p! = p + 2(p!)$$


$$(i - 1)m = p! \implies i = 1 + \frac{p!}{m}$$


Поскольку $1 \le m \le p$, число $m$ входит делителем в факториал $p!$, следовательно, величина $\frac{p!}{m}$ является целым положительным числом, а $i \ge 2$ — корректным целым параметром накачки.


5. **Противоречие:**
Для накачанной строки $w_i$:
$$n' + l = (p + p!) + p! = p + 2(p!) = k$$


Следовательно, равенство степеней нарушает базовое условие языка, значит $w_i \notin L_{28}$. Получено противоречие с леммой о разрастании, требующей принадлежности строки языку при любом $i \ge 0$.



**Вывод:** Язык $L_{28}$ не является регулярным.
